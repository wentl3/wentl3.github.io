Variants step by step

From: How many NICs does a PCIe GPU server need?

Each table below is one step of the sizing calculation, shown for all five variants of the same thirty-two servers: V0 is the official NVIDIA reference point, V1 to V3 change the number of GPUs, NICs and the topology, and V4 is an assumption. Read a table left to right: the variant, how the step is computed from earlier ones, the result, and what the result was checked against.
